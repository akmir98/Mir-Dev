01 — About

From pixels to processes.

How two years on the frontend shaped the way I think about backend work.

</> { } ⚡
Mir Nasrullah

I started as a frontend developer, spending two years turning designs into interfaces people actually enjoy using — clean layouts, smooth interactions, and code that holds up across screen sizes.

Building UI for two years taught me to think from the user's side of the screen. Now I'm applying that same care to backend development — learning how servers, APIs, and databases work so I can build the full picture, not just the part people see.

My goal is simple: become a full-stack developer who writes frontend that feels good and backend that holds up.
